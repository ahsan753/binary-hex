Why does a computer need three different number systems?

A computer only stores 1s and 0s. People are not good at reading 1s and 0s. Hexadecimal is the compromise that keeps both sides happy. By the end of this you will be able to convert between all three, and explain why hexadecimal exists at all.

Place value: the idea behind every number system

You already use place value every day. In denary, each column is worth ten times the one to its right. Change the digits below and watch the columns do the work.

Value
0

All columns are zero.

Binary works the same way, but each column is worth two times the one to its right, and the only digits allowed are 0 and 1. Hexadecimal columns are worth sixteen times the one to the right, and it needs sixteen different digits.

The base tells you two things: how many digits are allowed, and what each column is multiplied by.

Stage 5 of 10

Meet hexadecimal

Hexadecimal is base 16, so it needs sixteen digits. We run out of symbols after 9, so the letters A to F are used for the values ten to fifteen.

Notice what fits perfectly: four bits can hold sixteen different values, from 0000 to 1111. Hexadecimal has exactly sixteen digits. So one hexadecimal digit represents exactly one nibble. That is the whole trick, and it is why base 16 was chosen rather than, say, base 10.

4 bits = 1 nibble = 1 hexadecimal digit. 8 bits = 1 byte = 2 hexadecimal digits.

Binary to hexadecimal, and back

Split the byte into two nibbles. Each nibble is only four bits long, so each one has its own place values that start again at 8, 4, 2, 1. Convert each nibble on its own, then join the two digits together.

Both nibbles use the columns 8, 4, 2, 1. The left nibble does not carry on from 128, 64, 32, 16. Each nibble is a fresh, small number from 0 to 15, and that is exactly why hexadecimal is quick to work with.

Stage 7 of 10

Denary and hexadecimal

You can go straight between denary and hexadecimal, or you can hop through binary. Both are accepted in the exam as long as your working is clear.

Route 1: through binary

Denary 214 → binary 1101 0110 → nibbles 1101 and 0110 → 13 and 6 → D6

Route 2: divide by 16

214 ÷ 16 = 13 remainder 6. The 13 becomes D, the remainder 6 stays 6, giving D6. To go the other way: D6 means (13 × 16) + 6 = 208 + 6 = 214.

Stage 8 of 10

Why bother with hexadecimal?

Hexadecimal does not let a computer do anything new. The machine still stores binary. Hexadecimal exists entirely for the benefit of the people who have to read, write and check that binary.

Reason one: it is much shorter

32

Hexadecimal is always a quarter of the length of the same binary number, because each digit replaces four bits.

Reason two: people make fewer mistakes with it

Reason three: it is easy to convert, both ways

Converting binary to hexadecimal is quick and needs no calculation beyond counting to fifteen. Converting binary to denary is far more work, and denary does not line up neatly with the bits underneath it. Hexadecimal gives you a short number that you can turn straight back into the exact bit pattern.

Stage 9 of 10

Where hexadecimal is actually used

You need to be able to name areas of computer science that use hexadecimal. These are the ones the syllabus expects.

Colour codes in HTML and CSS

Every colour on a web page is three values: red, green and blue, each stored in one byte. Two hexadecimal digits per colour gives a six-digit code.

#3C6E71
60 = 3C
110 = 6E
113 = 71

MAC addresses

The unique address burned into a network interface card. It is 48 bits long, shown as six pairs of hexadecimal digits. Written in binary it would be 48 characters long.

00-1A-2B-3C-4D-5E

IP addresses (IPv6)

IPv6 addresses are 128 bits. They are written as eight groups of four hexadecimal digits, which keeps them just about readable.

2001:0DB8:85A3:0000:0000:8A2E:0370:7334

Memory addresses and memory dumps

When a programmer inspects the contents of memory, the addresses and the stored values are both shown in hexadecimal so that a whole screen of memory fits on the display and can be checked by eye.

004A2F10 4D 5A 90 00 03 00 00 00

Assembly language and machine code

Instructions and operands are written in hexadecimal when debugging low-level code, because it maps directly onto the bit pattern the processor receives.

B8 04 00 CD 21

Error codes and debugging

Operating systems report faults as hexadecimal codes. A short code is easier to read out, write down and search for than a long run of bits.

0x0000007B

ASCII and Unicode character codes

Character sets list their codes in hexadecimal. Capital A is 41 in hexadecimal, which is 65 in denary and 0100 0001 in binary.

U+0041

URLs

Characters that are not allowed in a web address are replaced by a percent sign followed by the hexadecimal code for that character. A space becomes %20.

search?q=data%20representation
